Automatisiert eintragen (iPhone-Kurzbefehle/Siri)

Mit diesem persönlichen Schlüssel kannst du dir einen iPhone-Kurzbefehl bauen, der per Siri dein Gewicht oder deine Ernährung einträgt, ganz ohne die App zu öffnen. Der Schlüssel ist geheim -- nicht teilen.

{{ api_token }}

Kurzbefehl "Gewicht" einrichten (Anleitung)
  1. App "Kurzbefehle" öffnen → "+" → "Aktion hinzufügen" → "Mitteilung anzeigen" suchen und hinzufügen → Text eintragen, z.B. "Wie viel wiegst du?"
  2. Danach "Diktat" hinzufügen → aufklappen → "Diktat beenden mit" auf "Bei Sprechpause" stellen (dann musst du am Ende nichts antippen)
  3. Danach "Inhalte von URL abrufen" hinzufügen. Ins URL-Feld eintragen: https://{{ request.host }}{{ url_for('api_gewicht') }}?token={{ api_token }}&wert=
  4. Direkt hinter wert= antippen → in der Leiste über der Tastatur "Diktatergebnis" auswählen (fügt einen blauen Chip ein, keinen echten Text)
  5. In derselben Aktion aufklappen → "Methode" von GET auf "POST" stellen
  6. Oben auf den Kurzbefehl-Namen/das Icon tippen → Namen vergeben (z.B. "Gewicht eintragen") → dort die Siri-Phrase aufnehmen

Nutzung: "Hey Siri, Gewicht eintragen" → Meldung erscheint kurz → Zahl sprechen → fertig.

Kurzbefehl "Ernährung" einrichten (Anleitung)

Vier Werte statt einem: Kalorien (Pflicht), Protein, Fett, Kohlenhydrate (alle drei optional -- bei Sprechpause ohne etwas zu sagen bleibt das Feld leer).

  1. Für jeden der vier Werte dieses Dreier-Paket hinzufügen: "Mitteilung anzeigen" (z.B. "Wie viele Kalorien?") → "Diktat" ("Diktat beenden mit" → "Bei Sprechpause") → "Variable festlegen" (neue Variable, z.B. "Kalorien", Wert = Diktatergebnis). Am Ende hast du 12 Aktionen (3 × 4, für Kalorien, Protein, Fett, Kohlenhydrate).
  2. Danach "Inhalte von URL abrufen" hinzufügen. Ins URL-Feld eintragen (die Variablen an den =-Stellen jeweils einfügen statt Text zu tippen): https://{{ request.host }}{{ url_for('api_ernaehrung') }}?token={{ api_token }}&kalorien=&protein=&fett=&kohlenhydrate=
  3. Methode auf "POST" stellen
  4. Namen vergeben (z.B. "Ernährung eintragen") und Siri-Phrase aufnehmen

Nutzung: "Hey Siri, Ernährung eintragen" → vier kurze Meldungen + Diktate nacheinander → fertig.

Falls eine Mitteilung nicht erscheint: Einstellungen → Mitteilungen → Kurzbefehle → "Mitteilungen erlauben" aktivieren.
